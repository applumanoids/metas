Privacidade e armazenamento de dados

Este aplicativo foi desenvolvido para funcionar com armazenamento local. As informações cadastradas são mantidas no próprio dispositivo e navegador utilizado.

Os dados cadastrados não são enviados para servidores externos, desde que o aplicativo não utilize recursos de sincronização ou serviços online.

A Lumanoids não recebe automaticamente os dados registrados no aplicativo.

Atenção: limpar os dados de navegação, excluir o armazenamento do site, reinstalar o navegador ou trocar de dispositivo pode resultar na perda das informações cadastradas. Recomendamos realizar backups periódicos para proteger seus dados.
